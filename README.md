# Rheinholz — GitHub Pages Demo

Statischer, GitHub-Pages-kompatibler Prototyp für Rheinholz.

## Enthalten
- Moderne Startseite im minimalistischen Manufaktur-/Sport-Look
- Produktbereich mit 3 Demo-Bats
- Warenkorb-Demo per JavaScript
- Custom Bats als **Vorbestellung** (kein Kauf im Demo)
- Responsive Design für Desktop und Mobile
- Keine Build-Tools, kein Backend nötig

## Lokal testen
Einfach `index.html` im Browser öffnen oder mit einem kleinen lokalen Webserver starten.

## GitHub Pages
Alle Dateien dieses Ordners in ein Repository laden und unter **Settings → Pages** die Branch-/Root-Auslieferung aktivieren.

## Später anschließbar
- echte Produktdaten
- Stripe / PayPal / Shopify Checkout
- E-Mail-Formular für Custom-Preorders
- eigene Rheinholz-Fotos und Logos
- Impressum, Datenschutz, AGB und Widerruf
